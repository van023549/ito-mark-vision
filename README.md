# ITO Mark Vision

玻璃基板 ITO Mark 视觉对位系统 —— 低对比度场景下的对位标记识别与对位精度优化。

## 项目背景

在玻璃基板上识别带防反射 ITO 涂层的对位标记（ITO Mark）属于典型的低对比度场景：
ITO 镀层的防反射特性会显著削弱标记与基板之间的灰度差异，导致传统阈值分割
和边缘检测方法失效。

本项目围绕完整的视觉对位链路（相机 → 镜头 → 光源 → 算法）进行协同调优。

## 硬件平台

| 组件 | 型号 |
|------|------|
| 相机 | XC-ES30 |
| 镜头 | FV5025 |
| 光源 | HEC-30B 同轴光源 |
| 视觉系统 | FAST FV-ALIGNER-UNT-FV133 (FV-Aligner II) |

## 研究方向

- **同轴光配相**：HEC-30B 同轴光源的入射角/亮度配相对低对比度 ITO Mark 成像的影响
- **打光方案**：不同照明方式（同轴、环形、暗场、明场）对 ITO 防反射涂层成像的对比度增强效果
- **识别算法**：低对比度条件下的亚像素边缘定位、模板匹配与特征增强
- **对位精度**：整机重复定位精度、相机标定误差补偿、对位算法收敛性
- **系统协同**：相机-镜头-光源-算法四者的联合调优
