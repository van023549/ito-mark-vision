# 硬件平台

## 视觉对位链路

```
ITO Mark (玻璃基板)
    ↓ 成像
HEC-30B 同轴光源 ──→ FV5025 镜头 ──→ XC-ES30 相机
    ↓ 图像
FV-ALIGNER-UNT-FV133 视觉对位系统
    ↓ 对位结果
执行机构
```

## 组件明细

| 组件 | 型号 | 作用 |
|------|------|------|
| 相机 | XC-ES30 | 图像采集 |
| 镜头 | FV5025 | 光学成像 |
| 光源 | HEC-30B 同轴光源 | 低对比度标记照明 |
| 视觉系统 | FAST FV-ALIGNER-UNT-FV133 | 对位算法与运动控制 |

## 同轴光配相要点

ITO 镀层的防反射特性会削弱标记与基板的灰度差异。同轴光源的关键在于：
- 入射角与 ITO 膜系反射率的匹配
- 亮度饱和与噪声的平衡
- 与 FV5025 镜头数值孔径的配合
